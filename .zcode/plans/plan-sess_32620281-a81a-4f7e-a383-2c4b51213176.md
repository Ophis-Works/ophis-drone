# Plan — preset folder = `presets/` beside the executable. No error taxonomy.

## The whole change

An executing executable is always at a path (`/proc/self/exe` always resolves, always absolute). No branches for impossible states. The single possible failure is the caller's output buffer not fitting.

### 1. `src/preset/preset.c` — delete `preset_dir_resolve` (lines ~50–98: the 3-candidate body, `getenv("OPHIS_PRESET_DIR")`, `getenv("HOME")`, comment blocks). `preset_dir()` becomes:

```c
int preset_dir(char *out, int out_len)
{
    char exe[1024];
    ssize_t n = readlink("/proc/self/exe", exe, sizeof exe - 1);
    exe[n] = '\0';
    char *slash = strrchr(exe, '/');
    int m = snprintf(out, (size_t)out_len, "%.*s/presets",
                     (int)(slash - exe), exe);
    return (m > 0 && m < out_len) ? 0 : -1;
}
```

### 2. `src/preset/preset.h` — delete the `preset_dir_resolve` declaration (line ~20) and its comment; leave only `preset_dir`, commented: "presets/ next to the running executable, computed at runtime from /proc/self/exe. No env var, no HOME, no fallbacks."
